# Documentation screenshot checklist

The usage documentation currently uses one completed screenshot and five placeholders. Capture the missing images at normal display scaling, crop them to the relevant application window or dialog, and do not include real hostnames, usernames, passwords, schema contents, or customer data.

| File | Documentation | Suggested content |
|---|---|---|
| `images/vscode_mysql_debugger.png` | Visual Studio Code | Existing paused-session overview. |
| `images/vscode_connection.png` | Visual Studio Code | Connection dialog with representative values; keep the password empty. |
| `images/netbeans_database_explorer.png` | NetBeans | Services tree and the **Debug in MySQL Routine Debugger…** context action. |
| `images/netbeans_debugger.png` | NetBeans | Loaded routine, breakpoint, paused line, Watches, and expanded Variable log. |
| `images/standalone_connection.png` | Standalone | Connection dialog and schema-discovery button; keep the password empty. |
| `images/standalone_debugger.png` | Standalone | Loaded routine, breakpoint, paused line, Watch panel, and expanded Variable log. |

After adding an image, replace the matching screenshot callout in the frontend usage guide with the Markdown image expression included in that callout.
